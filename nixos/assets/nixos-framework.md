# NixOS ASCII wallpaper

`nixos-framework.png` was rendered from the `nixos-fetch-preset` branch of the local ASCII wallpaper generator, commit `5894cb0`, with the bundled `nixos-framework.json` preset. The compositor label is Hyprland. The 2880×1920 preset matches the Fedora fetch layout, using a graphite background, the Fastfetch `nixos_old` ASCII logo and a NixOS light-blue swatch. Non-ASCII overlines were replaced with dashes for the generator. The logo attribution is in `NIXOS-ASCII-LICENSE.txt`. The bundled PNG requires no generator at install time.
