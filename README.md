# system-configs

Configurations for my machines, one directory per system.

- [`nixos/`](nixos/README.md): NixOS 26.05 with niri and a hand-written Quickshell desktop shell, for a Framework Laptop 13 Pro. The flake is at the repository root.
- [`fedora/`](fedora/README.md): Ansible for Fedora 45+, with two desktop profiles: GNOME with PaperWM (`desktop.yml`), and [Niri with the Noctalia shell](fedora/NIRI.md) (`niri.yml`).
