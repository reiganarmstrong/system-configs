# system-configs

Configurations for my machines, one directory per system.

- [`nixos/`](nixos/README.md): NixOS 26.05 with Hyprland and a hand-written Quickshell desktop shell, for a Framework Laptop 13 Pro. The flake is at the repository root.
- [`fedora/`](fedora/README.md): Ansible for Fedora Workstation with GNOME and PaperWM.
